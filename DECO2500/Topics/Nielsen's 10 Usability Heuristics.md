### **1. Visibility of System Status**

The system should always keep users informed about what is going on through timely and clear feedback.  
_Example: showing a loading spinner when a page is processing._

---

### **2. Match Between System and the Real World**

The interface should use concepts, language, and visuals familiar to users, following real-world conventions.  
_Example: using a shopping cart icon for online purchases._

---

### **3. User Control and Freedom**

Users should be able to undo or redo actions and easily exit unwanted states.  
_Example: a “Cancel” or “Undo” button._

---

### **4. Consistency and Standards**

Similar elements should behave and appear consistently across the system, following platform conventions.  
_Example: all “Save” icons use the same floppy disk symbol._

---

### **5. Error Prevention**

Design the system to prevent errors before they occur by guiding or restricting user actions.  
_Example: disabling a “Submit” button until all required fields are filled._

---

### **6. Recognition Rather Than Recall**

Minimise users’ memory load by making options and actions visible and easy to recognise.  
_Example: using icons and menus instead of requiring memorised commands._

---

### **7. Flexibility and Efficiency of Use**

Allow both novice and expert users to interact efficiently, often through shortcuts or customisation.  
_Example: keyboard shortcuts for frequent users._

---

### **8. Aesthetic and Minimalist Design**

Interfaces should avoid irrelevant information and visual clutter, focusing on essential elements.  
_Example: clean dashboards with only necessary data._

---

### **9. Help Users Recognise, Diagnose, and Recover from Errors**

Error messages should be clear, specific, and constructive, explaining the problem in plain language.  
_Example: “Incorrect password. Try again or reset it.”_

---

### **10. Help and Documentation**

Provide easily searchable help and instructions to support users when needed.  
_Example: a searchable help centre or tooltip hints._
